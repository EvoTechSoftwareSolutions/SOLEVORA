# SoleVora — Premium Footwear E-commerce 👟

**SoleVora** is a high-end, full-stack e-commerce platform dedicated to luxury footwear. Built with a focus on premium aesthetics and seamless user experience, it offers a complete shopping journey from discovery to delivery.

---

## 🌟 Key Features

### For Customers
- **Curated Collections**: Browse shoes by category, gender (Men, Women, Kids), size, and price range.
- **Localized Experience**: Fully localized for the Sri Lankan market with **Rs. (LKR)** currency formatting.
- **Smart Cart & Wishlist**: Real-time cart management and a personalized wishlist for registered users.
- **Secure Checkout**: Streamlined multi-step checkout process integrated with **PayHere** for secure payments.
- **Profile Management**: Manage multiple shipping addresses, track order history, and view personalized statistics.
- **Newsletter Subscription**: Modern welcome emails with exclusive discount codes (WELCOME10).

### For Administrators & Managers
- **Advanced Dashboard**: Real-time analytics on sales, revenue, and customer growth.
- **Product Management**: Full CRUD capabilities for products, including multi-image uploads and size variations.
- **Order Tracking**: Manage the fulfillment lifecycle from 'Pending' to 'Delivered'.
- **Inventory Reporting**: Comprehensive reports on stock levels and product performance.
- **Customer Management**: View and manage user accounts with role-based access control.

## 🛠️ Technology Stack

### Frontend
- **Core**: React.js (Vite)
- **Styling**: Vanilla CSS3 (Custom Design System), Material Symbols
- **State Management**: React Context API
- **Networking**: Axios

### Backend
- **Core**: Node.js, Express.js
- **Database**: MySQL
- **ORM**: Sequelize
- **Security**: JWT-based Authentication, Bcrypt Password Hashing
- **Email Service**: Nodemailer (support for HTML templates)
- **Payment Gateway**: PayHere API

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- MySQL Server
- NPM or Yarn

### 1. Database Setup
1. Create a database named `solevora_db` in your MySQL server.
2. The tables will be automatically generated by Sequelize when the backend starts.

### 2. Backend Configuration
1. Navigate to the `backend/` directory.
2. Create a `.env` file and configure the following:
   ```env
   PORT=5000
   DB_NAME=solevora_db
   DB_USER=your_mysql_user
   DB_PASS=your_mysql_password
   DB_HOST=localhost
   JWT_SECRET=your_secret_key
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the server:
   ```bash
   npm start
   ```

### 3. Frontend Configuration
1. Navigate to the `frontend/` directory.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
